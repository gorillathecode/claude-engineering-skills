# Example: describe a team contribution

## Synthetic input

A candidate has a merged PR adding a revocation notification to a team application. No evidence establishes ownership of the whole backend.

## Request

> Use Job Story Coach. Write a concise engineering-portfolio contribution statement from this evidence. Do not add metrics, production usage or sole-ownership claims.

## Acceptance criteria

- Describes the notification change as the candidate's contribution.
- Attributes the broader application to the team.
- Links the supplied PR when available.
- Does not invent performance gains, customer numbers or security guarantees.
- Keeps confidential details out of the public wording.

The scenario is illustrative and contains no real employer or customer data.
